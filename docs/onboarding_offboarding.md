# 入退社手続き

## 入社時の手続き
入社日までに、雇用契約書・マイナンバー・銀行口座の届出書を人事部へ提出する。入社初日に、情報システム部がアカウントと貸与PCを渡す。

## 試用期間
試用期間は入社から3か月とする。期間中の評価面談は、1か月後と2か月後に行う。

## 退職の申し出
退職を希望する場合は、退職希望日の1か月前までに、上長へ口頭で申し出たうえで、退職届を人事部へ提出する。

## 退職時の返却物
退職日までに、貸与PC、社員証、入館カード、会社名義のクレジットカードを返却する。返却の手続きは備品管理規程に従う。

## 退職時のアカウント
情報システム部は、退職日の24時にすべてのアカウントを停止する。業務データは、退職前に引き継ぎ担当者へ共有する。

## 退職後の手続き
離職票や源泉徴収票などの書類は、退職日から2週間以内に郵送する。住所が変わる場合は、人事部へ連絡する。
