# 情報セキュリティ方針

## 第1条 情報の分類
社内の情報は、公開・社内限定・機密の3段階に分類する。顧客の個人情報と未発表の財務情報は「機密」とする。

## 第2条 機密情報の持ち出し
機密情報は、社外に持ち出してはならない。やむを得ず持ち出す場合は、部門長の承認を得て、暗号化したうえで会社貸与の機器に限り保存する。

## 第3条 クラウドサービスと生成AI
会社が許可していないクラウドサービスに、社内情報を保存してはならない。外部の生成AIサービスには、「機密」に分類された情報や顧客の個人情報を入力してはならない。利用してよいサービスは、情報システム部が公開する許可リストで確認する。

## 第4条 USBメモリ
私物のUSBメモリを会社のPCに接続してはならない。業務で必要な場合は、情報システム部が貸し出す暗号化USBメモリを使う。

## 第5条 インシデントの報告
情報の漏えいや紛失、不審なメールの開封に気づいたときは、直ちに情報システム部へ報告する。報告は、気づいてから1時間以内に、チャンネル #security-alert で行う。報告が遅れたことのみを理由に処分することはしない。

## 第6条 年次研修
全従業員は、年1回の情報セキュリティ研修を受講する。未受講の場合は、システムの利用を制限することがある。
