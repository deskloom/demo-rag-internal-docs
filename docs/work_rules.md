# 就業規則（株式会社ミナトテック）

## 第1章 勤務時間
所定労働時間は1日8時間、週40時間とする。始業は9時00分、終業は18時00分で、12時00分から13時00分までを休憩時間とする。

## 第2章 フレックスタイム制
本社勤務の正社員はフレックスタイム制を選択できる。コアタイムは11時00分から15時00分とし、清算期間は1か月とする。フレキシブルタイムは7時00分から11時00分、および15時00分から21時00分とする。

## 第3章 時間外労働
時間外労働は事前に上長へ申請し、承認を得なければならない。時間外労働の上限は月45時間、年360時間とする。特別条項を適用する場合でも、時間外労働は月100時間未満とする。

## 第4章 遅刻・早退・欠勤
遅刻・早退・欠勤するときは、始業時刻前までに上長へチャットまたは電話で連絡する。連絡なしの欠勤が3日続いた場合は、所在確認のうえ人事部が対応を協議する。

## 第5章 副業・兼業
副業・兼業を希望する者は、事前に副業届を人事部へ提出し、承認を得る。競業にあたる業務、および本業に支障が出る業務は承認しない。承認は年度ごとに更新する。

## 第6章 懲戒
懲戒の種類は、戒告、減給、出勤停止、懲戒解雇とする。懲戒を行う前に、本人に弁明の機会を与える。
