# 在宅勤務規程

## 第1条 対象者
入社6か月を経過した正社員は、在宅勤務を利用できる。試用期間中の者と契約社員は、部門長が認めた場合にかぎり利用できる。

## 第2条 回数と申請
在宅勤務は週3日までとする。利用する日の前営業日までに、勤怠システム「タイムリーフ」で申請する。チームの定例会議がある日は、出社を優先する。

## 第3条 勤務場所
勤務場所は自宅に限る。カフェやコワーキングスペースなど、第三者に画面や会話が見える場所では、機密情報を扱う業務をしてはならない。

## 第4条 作業環境
会社貸与のPCを使い、私物PCは使用しない。業務中は必ずVPNに接続する。情報の取り扱いは情報セキュリティ方針に従う。

## 第5条 手当
在宅勤務者には、通信費として月額3,000円を定額で支給する。また、在宅勤務用の備品（モニター・椅子など）の購入補助として、入社後に1回のみ上限2万円を支給する。

## 第6条 勤務時間の報告
在宅勤務中も始業・終業の時刻を勤怠システムに記録し、業務開始時にチャットで開始を報告する。
