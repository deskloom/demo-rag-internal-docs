# 情報システム部 FAQ

## パスワードを忘れた場合
社内ポータルのログイン画面で「パスワードを再設定する」を選ぶと、登録済みの個人用メールアドレスに再設定リンクが届く。リンクの有効期限は30分である。届かない場合は情シスの窓口（チャンネル #it-help）へ連絡する。

## パスワードの規則
パスワードは12文字以上とし、英大文字・英小文字・数字・記号のうち3種類以上を含める。有効期限は90日で、直近5回に使ったパスワードは再利用できない。

## 多要素認証
社内システムへのログインには多要素認証が必須である。認証アプリ「ミナトパス」を使い、機種変更の際は旧端末を初期化する前に情シスへ申請して移行する。

## VPNの接続
社外から社内システムへ接続するときは、会社貸与PCに入っているVPNクライアントを使う。VPNに接続できない場合は、まずPCを再起動し、それでも直らなければ #it-help に接続エラーの画面を添えて連絡する。

## ソフトウェアのインストール
業務に必要なソフトウェアは、情シスの承認済みリストから自分でインストールできる。リストにないソフトウェアは、ソフトウェア利用申請を出して承認を受けてから導入する。

## 問い合わせ窓口の受付時間
情シスの受付時間は平日の9時30分から17時30分とする。受付時間外の障害は、翌営業日の対応とする。
